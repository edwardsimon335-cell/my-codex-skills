# Deconstruct 案例：可借鉴，不是所有 App 的强制样式

本 Skill 的引用图来自 Deconstruct 最终版首图。其他 App 必须使用自身 Logo、名称、实际 UI 和功能事实；不得因引用图而复制产品能力或品牌。

## 定版方向

- 双语各 8 张，1320×2868 纵向。前 3 张呈现照片分析 → 构图与光线 → 可执行复拍步骤。
- 石墨黑 `#101110`、暖白 `#EEECE5`、珊瑚红 `#D85743` 为品牌锚点，配合更明亮的粉彩艺术背景、色块、弧线和纸纹。
- 摄影采用自然光、日常生活、清晰肤色，不重复主素材。手机竖直、放大，避免过度重复同一页面。
- 中文海报字使用 Smiley Sans 得意黑，英文 Barlow Condensed ExtraBold。实际使用前重新确认字体文件和许可；本 Skill 不附带字体二进制。
- 以 1320px 画布为例：品牌 x84/y72、高44；标题起点 y200，品牌下沿至标题约84；中文152px/行高1，英文148px/行高1.02；标题与视觉主体至少48px。仅作为起点，需按实际字形与文案复核。
- 品牌英文为 `DECONSTRUCT`，中文版本增加“解构相机”；移除顶部功能标签和序号。不要把所有品牌名称强制大写。

## 迭代经验

1. 第一版影调太暗、UI 太重复：换成各页独立的明亮摄影，并重新分配界面证据。
2. 手机倾斜过多且太小：改为直立、放大、提高纵向利用率；保持截图原始宽高比。
3. 背景单调：只更新背景层的艺术色块和纹理，冻结文字与 UI。
4. 圆按钮出现方形残片：依据原生控件实现精确修正两处，而不是生成整张 UI。
5. 标题不够海报感：更换授权字体，并检查中英文真实字形与每页边界。
6. 品牌与标题过近：统一调整品牌上下呼吸空间，标题字号允许小幅响应式调整。
7. 清理历史：先让最终版本依赖自包含并校验，再移动明确旧目录到回收站。

## iPad 规格转换案例

原图1640×2360与目标2064×2752比例不同。曾采用等比缩放至1912×2752，左右各76px深色背景留边，保留全部 UI；没有拉宽界面或生成内容。其含义是适配画布，不是原生13英寸布局，新的转换仍需确认当时的 Apple 要求和用户偏好。
