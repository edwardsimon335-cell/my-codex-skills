# App Store Screenshot Studio

将产品事实、真实界面和摄影素材，组织成卖点直接、可编辑、可重复导出的商店图。默认中文沟通，输出语言服从用户需求。用户指令优先于案例默认值。

## 开始前

1. 读取 `artifact-template.json`，按本 Skill 目录解析路径并查看 `assets/reference.png`。保留引用图不变；它只展示构图范例，不是可拆分的 UI 源文件，也不授权在其他产品中复用其品牌或摄影人物。
2. 判断本轮是 **新建整套 / 指定局部修改 / 仅规格转换 / 历史清理**。先查找现有源文件、manifest、最新成品和工作区规则，再动手。不因上下文提过旧任务而重复执行。
3. 从用户和工程确认设备、语言、张数、功能、品牌、素材及修改边界；可以采用合理默认值，只有会改变结果方向的缺失信息才询问。
4. 开始前简述将采用本 Skill 的原因及本轮范围。新建/重设计阅读 `references/production.md`；沿用 Deconstruct 风格或针对旧版调整时再读 `references/deconstruct-case-study.md`。

## 四种工作模式

### A. 新建或重设计

按顺序完成：

1. **功能取证**：阅读当前实现和实际界面。写下每个宣传点的实现依据、付费限制和不能声称的能力。
2. **卖点脚本**：通常 7–9 张，每张只讲一个用户收益。前 3 张独立构成“是什么 → 如何帮我 → 我能得到什么”。短大标题配可辨认的真实 UI，避免功能清单堆砌。
3. **素材计划**：逐页分配不同主照片和不同界面状态。明亮自然、主体清楚、生活化优先；不要把“高级”误解为压暗影调。用户参考图主要提供光线和情绪方向。
4. **真实 UI**：用模拟器或连接设备采集非空状态。必要时在隔离预览副本中注入固定数据，不能写回业务工程。没有可运行界面时报告限制，不能把生成式仿 UI 当成真截图。
5. **分层制作**：至少 `background`、`ui`、`copy` 三层，可增加 `photography`、`accent`、`brand`、`retouch`。用 manifest 驱动 HTML/CSS/SVG 或同等可编辑格式。文字与品牌优先保持矢量/原生文字，真实 UI 按原始比例展示。同一设备的一套商店图统一手机界面的宽高比，默认统一展示尺寸；不要将局部 UI 裁片当成完整手机界面。弹窗、底部抽屉等状态使用包含底层原始页面、遮罩和弹窗的完整截图，不只展示弹窗内容；若另配弹窗前的截图，两张都保持同一设备比例。用户明确要求的局部特写除外。
6. **生成式素材**：需要新摄影、纹理或授权的图像修饰时加载并遵循 `$imagegen`。只生成相应素材层，不能用一次整图生成替代可编辑排版或真实 UI。纯排版、像素尺寸与格式转换用确定性工具。
7. **本地化与验证**：同一设计系统共享布局，分别检查语言长度、字体与 UI 本地化；执行下方验收，交付成品、总览、源文件和素材记录。

### B. 指定局部修改

先列出允许修改的层与冻结的层。例如“背景与品牌优化，文案和界面不变”意味着不得换标题、重画控件、替换摄影或刷新截图。优先改已有源文件，不对整张成品重新生成。

- 修改前记录冻结素材 SHA-256、manifest 内容与布局参数；修改后比较。
- 控件异常先确认是截屏、渲染还是缩放造成。优先重新截取；若需局部修复，依据真实实现，只修授权的遮罩区域，保留修复层与坐标记录。
- 区域之外应保持像素一致的修改，用遮罩外像素差验证；字体或布局变动则对冻结素材和语义内容验证，不能虚称全图像素一致。
- 未获授权不顺手修业务代码、换素材或改卖点。

### C. 仅设备尺寸/格式转换

先核对 Apple 官方当前截图规格和原图实际尺寸。保留原文件；按目标比例选择等比缩放加背景、轻微裁切或真实设备重截，明显裁切重要内容需要确认。不可非等比拉伸 UI。记录留边/裁切范围；转换不等于真实目标设备布局，也不保证审核通过。无需生成式重绘。

### D. 历史清理

只有用户明确要求才删除历史。先确定最新版本，查出其字体、UI、摄影、背景和脚本的跨版本依赖并收拢；验证可独立渲染后，将明确的旧目录移入回收站或其他可恢复位置。不得以工作区根目录为删除目标。告知删除范围及恢复方式。

## 必须执行的验收

- 每张满足当前目标设备认可的像素尺寸、PNG/JPEG 要求；本流程默认 PNG、8-bit RGB、sRGB、无 Alpha。可用 `scripts/validate-png.mjs` 检查 PNG；它不替代视觉、文案和商店政策审核。
- 主标题没有裁切或异常折行；中英文分别检查字体实际加载、字形覆盖、字重、字号层级和品牌到标题的呼吸空间。
- UI 等比、清晰；圆按钮仍然是圆，边框、网格、阴影无渲染残片；没有空状态、测试内容、意外水印、无关价格或未经证实的能力。
- 对比整套同设备 UI 容器的宽高比和展示尺寸；弹窗页仍须保留完整屏幕及底层页面上下文。不能只检查图片内部是否等比，而忽略裁切后手机外观比例不一致。
- 每页主摄影不重复；同页前后对比、同一页中英文复用是合理例外。用素材映射和哈希辅助检查，另目视排除不同裁切的重复照片。
- 联系表缩略查看所有页面，前 3 张仍能直接讲清核心价值；逐张放大查看 UI 细节。
- 至少实际渲染并检查一张代表页再批量导出；每次改共享样式后重新检查全部页面。
- 明确哪些是实际截图、生成摄影、真实滤镜输出或局部 Mock。没有运行或目视检查的部分标注“未验证”。

## 交付

使用独立且可识别的新版本目录，保护已有改动。交付语言分目录的最终图片、各语言总览、分层源文件、原始 UI、素材与字体许可、生成提示词、截图状态/Mock 范围、重渲染命令及验证报告。相对路径组织，不依赖本机绝对路径或已删除旧版本。

默认不上传 App Store Connect。最终简述本轮变化、验证状态及成品和源文件位置，不把规格检查称作苹果审核保证。
