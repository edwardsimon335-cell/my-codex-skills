# 政策与发布检查

逐项标记通过 / 不适用 / 未验证 / 阻塞。清单是建议验收标准，不代表历史所有站点均已达到。

## 内容与身份
- [ ] 品牌、产品名、平台、截图均属于当前产品。
- [ ] 首屏价值具体，真实功能与规划功能分开。
- [ ] 所有数字、评价、奖项与安全承诺有证据；无假数据、占位文本、无效按钮。
- [ ] 官网与 App/商店的功能、价格及权益没有冲突。

## 路由与转化
- [ ] 主 CTA 可用，商店 URL 的产品身份正确，未上线平台明确标识。
- [ ] 支持邮箱/表单真实可用；未经授权不发测试邮件或创建工单。
- [ ] 隐私、条款及适用的订阅/删除说明可直接打开，无需登录。
- [ ] 旧 URL、语言切换、重定向、404 行为有检查；不破坏 App 内政策链接。

## 产品边界
- [ ] 隐私文案匹配真实数据流和 SDK，不复制其他产品主体/邮箱/数据声明。
- [ ] 订阅的周期、试用、自动续订、取消与恢复说明经核实；不承诺平台退款结果。
- [ ] AI 功能、医疗或估价等限制准确，不把免责声明当成虚假能力声明的补救。
- [ ] 涉及大陆发布时，确认适用备案和主体条件；未备案不伪造备案号或宣称已合规。

## 体验与技术
- [ ] 手机及桌面关键宽度无横向溢出；标题、截图、CTA 可读可操作。
- [ ] 键盘焦点、对比度、语义标题、图像替代文本和 reduced-motion 处理合理。
- [ ] 图片体积与首屏加载合理；不存在明显失效资源或控制台错误。
- [ ] title、favicon、语义结构符合当前产品；未擅自改变既有索引/robots 配置。
- [ ] 若启用社交分享预览，分享内容正确。
- [ ] 无泄露密钥、用户内容或测试数据；分析脚本不重复，未擅自添加跟踪。
- [ ] 执行实际构建/测试并记录结果，无法执行时明确说明。

## 可选 SEO（未启用时标记不适用，不阻塞交付）
- [ ] 已记录是否启用；新站未指定时默认关闭，未擅自删除旧站 SEO。
- [ ] 仅在启用后验证计划内的 description、canonical、sitemap、hreflang、结构化数据及搜索内容。
- [ ] 没有为了 SEO 虚构内容或创建重复低价值页面；没有把关闭 SEO 等同于 noindex。

## 发布
- [ ] 目标环境、域名、变更范围明确且已获授权；保留可恢复的旧版本。
- [ ] 部署后检查实际页面及关键直达 URL；HTTP 成功不等于功能或视觉测试成功。
- [ ] 交付区分本地完成、预览发布、正式上线，不混淆状态。
