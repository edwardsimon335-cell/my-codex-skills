# 既有案例与复用边界

以下是 2026-10-27 对公开页面文本与结构的取样，不是移动端视觉、交互或性能验收。复用前重新读取实际网站与当前产品资料。不要把观察到的设计写成所有产品必须遵守的固定风格。

## Deconstruct

来源：https://deconstruct.jameshaoyu.com/

观察：短 Hero 主张、照片与产品 UI、构图/光线演示、滤镜对比、App AI 功能、浏览器图片工具、摄影 Guides、FAQ、Support、Terms/Privacy/Subscription、多语言（当次可见 14 种，含 RTL 语言）。

可复用：用真实结果证明价值；免费工具与文章可以提供下载之外的访问价值；官网工具、本地处理与 App 第三方 AI 的能力边界分开写。

不可固化：摄影配色、滤镜效果、工具数量、语言数量、价格、模型与隐私声明。官网 hostname 与 API hostname 不是同一个，禁止猜域名。

## ToneEQ

来源：https://toneq.jameshaoyu.com/

观察：Features / How it works / Guides / Support / Terms 导航；短主张、App Store CTA 与产品 UI；功能模块、三步流程、平台限制、Guides、FAQ、尾部下载入口；Product/Legal/Language/Contact 页脚；独立 Terms/Privacy/Subscription；当次可见 10 种语言。

可复用：按价值、证据、用法、疑虑与行动组织内容；明确平台不能做到什么。该站说明 Apple Music 软件 EQ 等限制，体现“营销不能超出真实能力”。

不可固化：音频文案、iOS 单平台、模块数量、所有产品都必须三步流程。

## 样本边界

这些案例仅代表上文列出的公开站点取样。搜索索引可能陈旧：首页、隐私页和商店若呈现不同上架状态，应重新核实，而非把搜索缓存当成当前事实。

本 Skill 中的响应式、可访问性、SEO 和发布检查是归纳后的建议标准，不代表所有样本站点已经通过这些检查。技能不附带某个产品的素材或政策文本，防止跨产品误用。
